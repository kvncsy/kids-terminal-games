# SECRET CODES    (type: secret)

MAKE A CODE: type a message and see it in lots of secret codes.
  letters      type your message
  ENTER        beeps it out in Morse code
  UP / DOWN    turn the code wheel
  TAB          switch to CRACK A CODE

CRACK A CODE: a secret message is scrambled.
  UP / DOWN    turn the wheel until it makes sense!
  ENTER        the next secret
  Esc          goes back to the menu

Try typing SOS, and try turning the wheel to 13!
